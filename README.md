AI Prompt Analyzer

A web application built with Next.js that allows users to analyze and optimize AI prompts. The app evaluates input prompts, provides feedback on their quality, and offers suggestions for improving them based on AI best practices.

Features

Prompt Evaluation: Analyze your AI prompts for clarity, structure, and effectiveness.

Feedback Suggestions: Get actionable recommendations on how to improve the quality of your prompts.

User Interface: Interactive and user-friendly interface built with Next.js.

Responsive Design: Optimized for both desktop and mobile devices.

Installation

To run this project locally:

Clone the repository:

git clone https://github.com/ifaz2611/ai-prompt-analyzer.git
cd ai-prompt-analyzer


Install dependencies:

npm install


Run the development server:

npm run dev


Visit http://localhost:3000
 in your browser.

Usage

Open the app in your browser.

Type or paste an AI prompt into the provided text area.

Click "Analyze" to get feedback and suggestions for improving the prompt.

Modify the prompt based on the recommendations and test it again.
